# Tasks: figure-image-extraction

PDF figure citations today carry a position (page + bbox + caption) but never
the image bytes. The lightbox overlays a purple bbox on the PDF page; the user
sees the region but cannot preview a clean crop, send the figure to a vision
LLM, download it, or cache it offline. This change ships a two-track v1 image
extraction pipeline (Mistral raster + render-crop vector), persists bytes to
S3, exposes an auth-gated proxy, and renders the crop in the lightbox with a
green/purple bbox color split. PR #1 is the backend foundation; PR #2 is the
frontend wiring; PR #3 is the gated local XObject path.
